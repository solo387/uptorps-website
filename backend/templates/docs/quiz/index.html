Quizzes API Documentation

Welcome to the Quizzes API

This API provides CRUD operations for the hierarchical quiz data (difficulty, level, programme, course, quiz, questions, answers) plus endpoints for students to start and submit quiz attempts. Most write operations require admin privileges; retrieval endpoints are open to authenticated users.

Base URL
/api/quizzes
Hierarchy
  • Difficulty → Level → Programme → Course → Quiz → Question → AnswerOption
ℹ️ Authorization
  • Read endpoints (GET) require authentication only
  • Create/update/delete require is_admin permission
  • Starting and submitting attempts require the CanAttemptQuiz permission (e.g., student role)
  • All requests and responses use JSON
GET POST PUT DELETE

/difficulty/

/api/quizzes/difficulty/

Manage Difficulty Levels

You can list, create, update, or delete difficulty entries.

GET: Authenticated POST/PUT/DELETE: Admin
GET Query Parameters

None. Returns all difficulties.

POST Request Body
Parameter Type Required Description name string REQUIRED Unique name description string REQUIRED Text description
PUT Request Body

Include pk of existing difficulty along with name and description.

DELETE Query Parameters

?name=<difficulty name>

Responses
200 OK – for GET/PUT 201 Created – for POST 204 No Content – for DELETE 400 Bad Request – invalid data
Example cURL
curl -X POST https://api.uptorps.com/api/quizzes/difficulty/ \ -H "Authorization: Bearer <token>" \ -H "Content-Type: application/json" \ -d '{"name":"Beginner","description":"Easy quizzes"}'
Example React (Fetch)
await fetch('/api/quizzes/difficulty/', { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${token}` }, body: JSON.stringify({ name:'Beginner', description:'Easy quizzes' }) });

/level/

/api/quizzes/level/

Manage Levels

Levels belong to difficulties. You must specify the difficulty when querying or creating.

GET: Authenticated POST/PUT/DELETE: Admin
GET Query Parameters
Parameter Description
difficulty Name of difficulty (required)
POST Body
Parameter Type Required name string REQUIRED difficulty string REQUIRED
PUT Body

Include pk plus updated name/difficulty (if changed).

DELETE Query Params

?difficulty=<name> deletes all levels under that difficulty.

Example React
// fetch levels for a difficulty const res = await fetch(`/api/quizzes/level/?difficulty=Beginner`, { headers: { Authorization: `Bearer ${token}` } }); const data = await res.json();

/quiz/

/api/quizzes/quiz/

Manage Quizzes

Quizzes belong to a course; retrieving requires difficulty/level/programme/course in query parameters. Creation uses multipart POST form fields for relational lookup.

GET: Authenticated POST/PUT/DELETE: Admin
GET Query Params
  • difficulty
  • level
  • programme
  • course
POST Form Fields
  • title (string)
  • description (string)
  • is_paid (boolean)
  • duration_minutes (integer)
  • difficulty, level, programme, course (to identify parent)

/attempt/start/<quiz_id>/

/api/quizzes/attempt/start/<uuid:quiz_id>/

Begin a Quiz Attempt

Creates or retrieves an existing attempt object for the authenticated user. Returns quiz structure and attempt ID. Required permission CanAttemptQuiz.

Authenticated
Response Format
{ "attempt_id": 12, "quiz": { "uuid": "...", "title": "Sample Quiz", "questions": [ ... ] } }
Example React
const res = await fetch(`/api/quizzes/attempt/start/${quizId}/`, { method: 'POST', headers: { Authorization: `Bearer ${token}` } }); const data = await res.json();

/attempt/submit/

/api/quizzes/attempt/submit/

Submit Quiz Answers

Send user's answers for grading. The server calculates score, percentage, and marks attempt completed. Requires CanAttemptQuiz.

Authenticated
Request Body
{ "attempt_id": "uuid-or-int", "answers": [ {"question_id": "uuid", "selected_options": ["uuid1","uuid2"]}, ... ] }
Example React
await fetch('/api/quizzes/attempt/submit/', { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${token}` }, body: JSON.stringify({ attempt_id: attemptId, answers: userAnswers }) });
Example Response
{ "score": 8, "total": 10, "percentage": 80.0 }

Notes

  • All write operations require admin; student UI should hide these links.
  • Quiz duration (in minutes) is stored on the quiz model but timing enforcement happens on frontend or later backend checks.
  • The CanAttemptQuiz permission may check course enrollment or other business rules.
  • Delete routes are destructive; consider soft-delete in future.
